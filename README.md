# N0T3B00K

Приложение для ведения задач и документов

## О проекте

N0T3B00K - это веб-приложение, предназначенное для управления задачами и документами. Оно позволяет пользователям создавать, редактировать и удалять задачи, а также хранить и организовывать документы.

## Структура проекта

Проект состоит из двух основных частей:

- **api/**: Серверная часть приложения, написанная на Python, которая предоставляет REST API для взаимодействия с данными.
- **web/**: Клиентская часть приложения, написанная на JavaScript, которая предоставляет пользовательский интерфейс для взаимодействия с приложением.

## Установка

Для установки и запуска проекта выполните следующие шаги:

1. Клонируйте репозиторий:

    ```sh
    git clone <URL репозитория>
    ```

2. Перейдите в директорию проекта:

    ```sh
    cd N0T3B00K
    ```

3. Установите зависимости для серверной части:

    ```sh
    pip install -r api/requirements.txt
    ```

4. Установите зависимости для клиентской части:

    ```sh
    cd web
    npm install
    ```

## Запуск

Для запуска проекта выполните следующие команды:

1. Запустите серверную часть:

    ```sh
    cd api
    python main.py
    ```

2. Запустите клиентскую часть:

    ```sh
    cd web
    npm run dev
    ```
